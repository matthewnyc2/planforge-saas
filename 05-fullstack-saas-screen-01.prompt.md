# PlanForge Landing Page

## Overall Vibe
Modern, clean, professional web application interface. Inspiring and trust-building for teams considering project management software. Hero-first layout with strong visual hierarchy and clear call-to-action buttons.

## Design System
- Typography: Tailwind CSS utility classes, semantic heading sizes
- Color Palette: Professional blues and greens with neutral grays; primary action button accent color
- Spacing: Generous whitespace; 16px, 24px, 32px, 48px spacing increments
- Buttons: Primary (accent color, hover state with darker shade), Secondary (outline), CTA buttons with arrow icon

## Page Structure
1. Navigation Bar (fixed/sticky top)
   - Logo "PlanForge" left-aligned
   - Nav links: Features, Pricing, Demo (center)
   - "Get Started" and "View Demo" buttons (right, primary + secondary styles)
   - Hamburger menu for mobile

2. Hero Section
   - Main headline: "Organize Projects, Execute With Clarity"
   - Subheadline: "Modern project management for teams who move fast"
   - Two prominent CTA buttons: "Get Started Free" (primary) and "View Demo" (secondary)
   - Subtle background color or gradient
   - Hero image/illustration placeholder (right side on desktop)

3. Features Section
   - Headline: "Precision Engineering for Productivity"
   - 4 feature cards in a grid (mobile: stacked, desktop: 2-3 per row):
     * Authentication & User Management (icon + description)
     * Kanban Task Board (icon + description)
     * Project Management (icon + description)
     * Dashboard & Analytics (icon + description)
   - Each card: icon at top, bold title, supporting description text

4. Pricing Section
   - Headline: "Scalable Plans for Every Stage"
   - Three pricing tiers (cards with descriptions):
     * Starter: Basic features, button "Get Started"
     * Pro: Advanced features, button "Go Pro Now" (highlighted/featured tier, most popular badge)
     * Enterprise: Custom pricing, button "Contact Sales"
   - Toggle for monthly/annual billing
   - Feature comparison under tiers

5. Footer Section
   - Logo, company tagline
   - Links sections: Product, Company, Legal
   - Social media icons
   - Copyright notice
