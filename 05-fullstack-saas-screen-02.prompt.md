# PlanForge Project Kanban Board

## Overall Vibe
Workspace-focused task management interface with clear visual organization. Interactive drag-and-drop board supporting workflow visualization. Professional, clean design with attention to task priority and team collaboration.

## Design System
- Typography: Manrope for headlines, Inter for body text
- Color Palette: Blue primary, green secondary, with priority indicators (red for high, orange for medium, gray for low)
- Spacing: 16px baseline grid
- Cards: Subtle shadows, minimal borders, color-coded by priority
- Icons: Material Design icons for actions

## Page Structure
1. Top Navigation Bar
   - Project name: "Website Redesign"
   - View toggle options (List, Board, Calendar)
   - Search bar and filter options
   - Team member avatars
   - Add task button

2. Left Sidebar
   - Projects list with icons
   - Dashboard link
   - Settings link
   - Team members section

3. Main Content Area - Kanban Board
   - Three columns: "To Do", "In Progress", "Done"
   - Each column header shows task count
   - Add task button (+) at column footer
   - Column background: light surface color
   
4. Task Cards (draggable)
   - Task title
   - Assignee avatar (initials or image)
   - Priority badge (High/Medium/Low with color)
   - Due date if applicable
   - Subtle shadow, corner radius
   - Hover state with slight elevation

5. Task Data Examples
   - "Setup database schema" - Alice (High priority) - Red badge
   - "Create API endpoints" - Bob (High priority) - Red badge
   - "Design UI components" - Carol (Medium priority) - Orange badge
   - "Write documentation" - Alice (Low priority) - Gray badge
