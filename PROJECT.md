# 05 - Full-Stack SaaS Application

## Upwork Category
Full-Stack Web Development — $50-150/hr, HIGH demand

## GitHub Base

## Portfolio Story
A complete SaaS starter with auth, payments, email, admin dashboard, landing page, and blog. Shows you can ship a full product, not just features. Domain: project management / team collaboration tool.

## Key Features to Showcase
- User auth (email, Google, GitHub)
- Stripe subscription billing
- Admin dashboard with analytics
- Email integration (transactional + marketing)
- Landing page with pricing tiers
- User settings and profile management
- Database with Prisma ORM
